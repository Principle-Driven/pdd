# SITE-05 — Show the complete decision system
Token: SITE-05
Version: v1

## Statement

Do not present a principle file as the complete method. Show how the index, citations, comments, reviews, and CLI make the rule operational.

Each public explanation must connect the rule to its use and enforcement.

## Rationale

A principle library is ordinary documentation. It cannot show which code depends on a rule or which comments became old.

Pinned citations connect the rule to real decisions. Comments state the local dependency, and the CLI checks each current pin.

Together, these parts create one decision process across developers and agents.

## Implications

- The website shows the complete system before it shows the catalog.
- The blueprint teaches comments and citations as required parts.
- The CLI checks principle files, index entries, citations, and risk markers.
- A version change lists every site that needs a new review.
- “Working as designed” requires a current pinned token.
